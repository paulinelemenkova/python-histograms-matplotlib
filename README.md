# Histograms with Python and Matplotlib

Python/Matplotlib script drawing histograms of morphometric variables, demonstrated on Mariana Trench data. Reusable scientific-plotting example.

## Scripts

- `hist.py`

## Data

- `Tab-Morph.csv`

## Requirements

Python 3 with `matplotlib`, `pandas`, `seaborn`.

```
pip install matplotlib pandas seaborn
```
